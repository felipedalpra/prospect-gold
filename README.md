# Golden Opportunity Engine

Quero que você crie uma plataforma SaaS completa para automatizar prospecção de empresas locais através do Google Maps.

A ideia da plataforma é permitir que freelancers, agências, desenvolvedores e vendedores encontrem empresas que precisam de presença digital, gerem automaticamente uma landing page personalizada para aquele negócio e recebam uma abordagem comercial pronta para enviar.

O fluxo principal deve ser:

Encontrar leads → Qualificar → Gerar site demo → Publicar → Gerar abordagem → Gerenciar a prospecção

Quero que você crie tanto a landing page pública da plataforma quanto o dashboard interno do SaaS.

RESPONSIVIDADE

Desktop deve ser prioridade para o dashboard.

Landing page precisa ficar excelente tanto em desktop quanto mobile.

No mobile, adaptar animações para não comprometer performance.

ANIMAÇÕES

Use animações elegantes.

Prefira:

Framer Motion

CSS transforms

Intersection Observer

scroll-based animations

Evite animações pesadas que prejudiquem performance.

Quero que o usuário tenha uma sensação constante de que a plataforma está processando, encontrando e construindo coisas.
